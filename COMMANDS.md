# Команды бота (для админов)

> Все команды работают **только в ЛС с ботом** (`@asvet_probot`). В самом чате бот команд не слушает — это специально, чтобы не палить список админов.

## Получить ID

```
/id
```

Ответит:
```
chat_id = -1002211025843
user_id = 364321954
CHAT_ID в .env = -1002211025843
```

`/id` работает в любом чате (в том числе в ЛС), удобно для отладки.

## Баны

### Постоянный бан

```
/ban @user причина
```

или

```
/ban (реплай на сообщение) причина
```

Примеры:
```
/ban @spamer_228 реклама казино
/ban (реплай) продажа курсов
```

### Временный бан

```
/tban @user <минуты> [причина]
```

Примеры:
```
/tban @fluder 30 флуд
/tban (реплай) 60 повторный спам
```

### Разбан

```
/unban @user
```

или

```
/unban (реплай)
```

## Белый список

```
/whitelist_add @user    # добавить
/whitelist_del @user    # убрать
```

В вайтлисте пользователь проходит мимо всех фильтров (антифлуд, спам, капча). Используй для проверенных участников: модераторов, постоянных авторов.

## Подсказка по аргументам

| Что | Как передать | Пример |
|---|---|---|
| `@username` | начинается с `@` | `/ban @spamer` |
| Числовой `user_id` | просто число | `/ban 123456789` |
| Reply | просто пустой первый аргумент, бот возьмёт `from_user` реплая | `/ban причина` (реплай) |

Если username не резолвится (бывает) — попроси жертву зайти к тебе в ЛС или посмотри `user_id` через `/id` в нужный момент.

## Бот молчит в ЛС?

Проверь, что твой Telegram ID указан в `ADMIN_IDS` в `.env`. После изменения — перезапусти бота.
